# AGENTS.md

Назначение: консольный переводчик; `main.py` читает меню и вызывает `GoogleTranslator` из `deep_translator`.
## Карта файлов

| Файл | Роль |
|---|---|
| `main.py` | `translate_text()` и интерактивное меню |
| `start.cmd`, `start.sh` | запуск через `py` / `python3` с venv |
| `README.md`, `AGENTS.md` | документация |
## Запуск и проверка

`pip install deep-translator` → `python main.py`.
Тестовой команды нет; не выдумывай тесты без запроса пользователя.
## Соглашения

- Подсказки в CLI и документация — на русском.
- Коды языков переводятся в нижний регистр перед вызовом `GoogleTranslator`.
## Подводные камни

- Перевод сетевой: без интернета не работает.
- `start.sh` предполагает наличие `venv/bin/activate`.
- `requirements.txt` нет; `int(input(...))` упадёт на нечисловом вводе.
